# Visual assets

## Original artwork
`frontend/src/components/CarArt.jsx` contains original SVG artwork generated
with Perplexity assistance. It is retained as the image-loading fallback.

## External representative photographs
The frontend embeds these fixed Unsplash image URLs:

- https://images.unsplash.com/photo-1492144534655-ae79c964c9d7
- https://images.unsplash.com/photo-1503376780353-7e6692767b70

These photographs are representative automotive imagery.
They do not depict the actual inventory vehicles and are not verified
matches for the listed make, model, year, trim, or market.

License information: https://unsplash.com/license

No image files are stored in this repository.
External availability depends on the provider and network access.
The interface falls back to original SVG artwork if loading fails.

Before final submission, verify the original photo pages and record
photographer credits where available.
