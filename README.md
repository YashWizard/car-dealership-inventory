# Car Dealership Inventory System

A full-stack inventory application being developed using FastAPI,
SQLite, React, and Tailwind CSS.

## Status

Initial setup is in progress.
Application functionality and tests are not yet implemented or verified.

## Features

Planned functionality:
- User registration and login.
- Token-protected vehicle and inventory APIs.
- Vehicle creation, listing, search, and update.
- Admin-only deletion and restocking.
- Purchasing with stock validation.
- Responsive React and Tailwind interface.

Completed features will be recorded after verification.

## Technology Stack

- Backend: Python, FastAPI, SQLAlchemy
- Database: persistent, file-backed SQLite
- Authentication: JWT and Argon2 password hashing
- Frontend: React, Vite, Tailwind CSS
- Backend testing: pytest, pytest-cov, HTTPX
- Planned frontend testing: Vitest, React Testing Library
